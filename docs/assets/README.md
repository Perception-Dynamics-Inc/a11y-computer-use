# Brand assets

Dark navy `#0B1220`, electric blue `#2A8CFF`, white. The mark is a cursor arrow with an accessibility tree inside.

| File | Use |
|---|---|
| `banner.png`, `banner-platforms.png` | previous README header, wide (1600 px) |
| `logo.png`, `logo-alt.png`, `logo-transparent.png` | avatar, favicon, overlays |
| `social-preview.png` | GitHub Settings > Social preview (1280x640): a real Calc demo frame plus the name and tagline |
| `social-preview-v1.png` | the earlier social preview (1280x714) |
| `alternatives.png`, `backends.png`, `safety-gate.png`, `observe-act.png` | figures in docs/comparison.md, docs/platforms.md, docs/safety.md (`observe-act.png` is not used) |
| `demo-calc.gif`, `demo-calc.mp4` | README demo: recorded on Xvfb with ffmpeg x11grab, LibreOffice Calc driven through `Runtime`, visible-actions overlay on, real time |
| `tree-snapshot.png`, `overlay-highlight.png` | README screenshots: an excerpt of `a11y-computer-use snapshot --app soffice` and a frame of the overlay labelling a click |

The brand images were generated with Higgsfield (nano_banana_pro), downscaled and palette-compressed. The demo, screenshots and social preview come from real recordings. Excluded from the sdist.
