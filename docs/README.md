# Documentation index

Everything under `docs/` in one place: the Phase-0 decision records, the per-backend port notes, the agent-loop, adapter, observation-cost, benchmark, and test-bed notes, the data behind the demand claim, and the brand assets. Status and date entries are copied from each document's own header; where a document has no header, the table says so.

## Examples (`../examples/`)

| File | What it does |
|---|---|
| [examples/README.md](../examples/README.md) | The two integration shapes (in-process Python, MCP subprocess), the diagnostic and the three agent-loop and adapter scripts, what each script does, how to run them on macOS and against the browser, Windows, and Linux backends, and the macOS integrator checklist. |
| [examples/inprocess_python.py](../examples/inprocess_python.py) | Grants `read` for `com.apple.finder`, builds `server.Runtime`, prints a window snapshot, counts the interactive refs; act calls shown as comments only. |
| [examples/mcp_subprocess.mjs](../examples/mcp_subprocess.mjs) | Node MCP client that spawns `computeruse mcp` over stdio, lists tools, and calls `desktop_snapshot` on Finder. |
| [examples/web_a11y_demo.py](../examples/web_a11y_demo.py) | macOS-only before/after: snapshots a running Chromium/Electron app with the accessibility force-enable off (`COMPUTERUSE_NO_WEB_A11Y=1`) and on, and prints the element and interactive counts. |
| [examples/agent_task.py](../examples/agent_task.py) | Runs one task in process with the reference agent loop (`computeruse.agent.run_task`, the loop behind `computeruse agent`): planner from `computeruse.providers.get_provider` (`COMPUTERUSE_PROVIDER`, else the first the environment supports: an Anthropic key, an OpenAI key or base URL, the `claude` CLI; no offline mode), backend from `COMPUTERUSE_DRIVER`, and a `full` grant for the frontmost app or bound tab set first. Not run by tests or CI. |
| [examples/anthropic_computer_use.py](../examples/anthropic_computer_use.py) | Anthropic computer-use loop executed through `AnthropicComputerAdapter` (model `claude-opus-5`, up to 40 turns); with `ANTHROPIC_API_KEY` or `ANTHROPIC_AUTH_TOKEN` and the `anthropic` package it calls the API, otherwise it replays a six-action scripted sequence through the adapter. `COMPUTERUSE_APP` names the app whose tree backs snap-to-ref. Exercised in scripted mode only; not run by tests or CI. |
| [examples/openai_computer_use.py](../examples/openai_computer_use.py) | OpenAI Responses-API computer-use loop executed through `OpenAIComputerAdapter` (up to 40 turns); with `OPENAI_API_KEY` and the `openai` package it calls the API, otherwise it replays one scripted `computer_call` with five actions. `OPENAI_COMPUTER_MODEL` (default `gpt-5.4`) and `OPENAI_COMPUTER_PREVIEW=1` (the deprecated `computer_use_preview` shape) select the model and tool shape. Exercised in scripted mode only; not run by tests or CI. |
